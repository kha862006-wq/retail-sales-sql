# Retail Sales Analysis Using SQL Server

## Project Overview
This project analyses retail sales data using Microsoft SQL Server to identify sales trends, profitability patterns, employee performance, and customer segment performance.

## Tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## SQL Skills Used
- JOIN
- GROUP BY
- CASE
- CTE
- Window Functions
- RANK()
- User-Defined Functions
- Stored Procedures
- Dynamic SQL
- PIVOT

## Analysis
1. Quarterly Furniture Sales Analysis
2. Discount Tier and Profit Analysis
3. Top Product Categories by Customer Segment
4. Employee Profit Contribution by Product Category
5. Employee-Category Profitability Ratio
6. Employee Sales and Profit by Date Range
7. Dynamic Quarterly Profit Pivot by State

## Process
- Imported retail datasets into SQL Server.
- Joined customer, product, order and employee tables.
- Created queries to analyse sales and profit performance.
- Used CTEs and window functions to rank categories and calculate contribution percentages.
- Created a user-defined function to calculate profitability ratios.
- Created stored procedures for employee sales analysis.
- Used dynamic SQL to generate a quarterly profit pivot by state.

## Insights
Insights were generated from the query outputs, including sales trends, profitability by category, employee contribution, and quarterly profit performance.

## Recommendations
Based on the analysis, the results can be used to:
- Monitor high and low-performing product categories.
- Review the impact of discount levels on profitability.
- Compare employee performance across product categories.
- Track profit trends across states and quarters.
