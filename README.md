# Retail Sales Analysis Using SQL Server

## Project Overview
This project analyses retail sales data using Microsoft SQL Server to explore sales performance, profitability, customer segments, discount levels, and employee performance.

## Tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## SQL Skills Used
- JOIN
- GROUP BY
- CASE
- CTE
- Window Functions
- RANK()
- User-Defined Functions
- Stored Procedures

## Analysis
1. Quarterly Furniture Sales Analysis
2. Discount Tier and Profit Analysis
3. Top Product Categories by Customer Segment
4. Employee Profit Contribution by Product Category
5. Employee-Category Profitability Ratio
6. Employee Sales and Profit by Date Range

## Process
- Imported retail datasets into SQL Server.
- Joined customer, product, order and employee tables.
- Analysed quarterly sales performance for furniture products.
- Classified orders into different discount levels and compared profitability.
- Used CTEs and window functions to rank product categories by customer segment.
- Calculated each product category's contribution to employee profit.
- Created a user-defined function to calculate profitability ratios.
- Created a stored procedure to analyse employee sales and profit within a selected date range.

## Insights
The analysis focused on:
- Sales performance across quarters.
- Profitability differences across discount levels.
- High-performing product categories within customer segments.
- Employee profit contribution by product category.
- Profitability ratios across employee-category combinations.
- Employee sales and profit performance over selected date ranges.

## Recommendations
The results can support business decisions by:
- Monitoring sales trends across different quarters.
- Reviewing discount levels that may reduce profitability.
- Identifying strong product categories within each customer segment.
- Comparing employee performance across product categories.
- Using profitability ratios to identify more profitable employee-category combinations.
